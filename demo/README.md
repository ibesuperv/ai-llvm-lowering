## 📄 Sample Generated IR Files

Real pipeline outputs — generated by Llama 3.3 70B (Groq), validated by `llvm-as` + `lli`.

- Input: `add(20, 22)` → Expected: `42`
- Constructs: `alloca`/`store`/`load`, `add i32`, `declare @printf`, opaque `ptr`

### `14_recursion.ll` — Tier 3 ✅ Pass after 1 repair
- Input: `fibonacci(10)` → Expected: `55`
- Attempt 0 failure: `target datalayout = "e-m:e-p:32:32-..."` (32-bit pointers on 64-bit system → SIGSEGV)
- Repaired: correct 64-bit datalayout + `fibonacci(n-1) + fibonacci(n-2)` logic
